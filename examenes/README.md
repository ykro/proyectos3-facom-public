# Exámenes (curso finalizado)

Los **exámenes escritos** que se aplicaron durante el trimestre julio–septiembre 2026, publicados **al cierre del curso** como material de repaso y referencia. Cada examen fue **100 % escrito y en línea, sin defensa**: 100 puntos (Teoría 40 % + Práctica 60 %) que se convirtieron íntegramente a los 20 puntos del examen.
