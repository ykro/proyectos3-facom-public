# Material de apoyo entregado en clase

Documentos y ejemplos que el docente compartió durante el trimestre, además de las guías y las asignaciones.

| Archivo | Qué es |
|---------|--------|
| `Proyecto de Curso — Proyectos III · Diseño de aplicaciones móviles.pdf` | Especificación del **Proyecto de Curso**: app propia (en parejas), con sus ocho etapas —concepto, identidad visual, datos, autenticación, PWA instalable y publicación, lanzamiento— y lo que se entrega en el PDF y en el pitch con demo en vivo |
| `Especificación de entrega — Caso de portafolio + pitch.pdf` | Qué debe tener el **caso de portafolio + pitch**: problema, proceso, capturas y script del pitch con marcas de tiempo |
| `Ejemplos de entrega — Caso de portafolio + pitch.pdf` | Dos casos de ejemplo resueltos (Duolingo y Waze) con la estructura exacta de la entrega |
| `Deck_ejemplo_Duolingo.pptx` / `Deck_ejemplo_Waze.pptx` | Decks de pitch de ejemplo (problema → demo → proceso → cierre), uno por caso |
| `Ejemplo Store Listing.pdf` | Ficha de tienda de ejemplo (Splitwise): título con palabra clave, descripción corta y larga, categoría y capturas |
| `Proyectos III — Diseño de aplicaciones móviles.pdf` | Deck de apoyo sobre **Stitch** (stitch.withgoogle.com) y librerías de ejemplos y recursos: animación, componentes de interfaz, íconos, exportar de Stitch a Figma y código vs. .zip |

> Las plantillas en Markdown de la ficha de tienda, el caso de portafolio y el pitch están en `guias-estudiante/`.
